# Пользовательская версия LG Hue Sync

Основа — открытый проект [adeze/lg-hue-sync](https://github.com/adeze/lg-hue-sync), тег [`v1.1.0`](https://github.com/adeze/lg-hue-sync/releases/tag/v1.1.0). Автор исходного проекта — Adam (adeze). Лицензия MIT сохранена.

## Что добавлено

- русская веб-панель управления;
- захват HDMI, локального медиаплеера, YouTube, Кинопоиска, Lampa и Иви с отдельными переключателями;
- статическая подсветка и сцены на домашнем экране, автоматическое включение и выключение вместе с ТВ;
- кнопка полного перезапуска службы из веб-панели;
- режим 30 FPS и автоматические 60 FPS для HDMI;
- компенсация чёрных полос, порог тёмных оттенков и дополнительные настройки цвета;
- музыкальные вспышки от ALSA/UDP с раздельной чувствительностью и силой для Nanoleaf, кольца и верхнего света торшера;
- управление торшером **Govee C60B0** через **ESP32-S3** и Bluetooth Low Energy (BLE): LG передаёт ESP32 цвет и параметры эффекта по локальной сети, ESP32 преобразует их в BLE-команды торшера;
- раздельное управление цветом, кольцом и верхним светом Govee C60B0, включая независимые музыкальные вспышки;
- API для внешнего контроллера торшера: `lamp_music_mix` и `lamp_top_music_mix`;
- точная поправка координат верхнего и левого края Nanoleaf 4D через файл `nanoleaf-edge-map`;
- диагностика захвата, предпросмотр зон и восстановление после зависания захвата.

## Калибровка Nanoleaf 4D

В веб-панели откройте «Устройства» → «Расположение ленты Nanoleaf». Запустите «Бегущий сегмент 4D», затем выберите физическое начало ленты, проверьте направление и подстройте смещение по периметру. Проверьте углы по [тестовой сетке](calibration-patterns/01-position-grid.png) и сохраните настройки.

Для точной коррекции верхнего и левого краёв создайте рядом с `config.json` файл `nanoleaf-edge-map` с четырьмя числами через запятую. Порядок полей — масштаб верха, сдвиг верха, масштаб левого края, сдвиг левого края. Для каждого края формула `новая координата = масштаб × координата + сдвиг`; координаты нормированы от 0 до 1. Масштаб допустим от 0,5 до 1, сдвиг — от 0 до `1 − масштаб`. Используйте точку как десятичный разделитель. Измерьте положение двух тестовых меток на каждом краю, чтобы подобрать масштаб и сдвиг, затем перезапустите службу. Без файла действует штатная раскладка.

Для захвата звука укажите в локальном файле `music-audio` источник в формате `alsa:ИМЯ_УСТРОЙСТВА`. Имя устройства зависит от телевизора. Также поддерживается UDP-вход с заданного адреса.

## Сборка и установка

Команды сборки и требования описаны в исходном [README.md](README.md) и [docs/operations.md](docs/operations.md). После изменения панели выполните:

```bash
make dashboard-build
make build
```

Обновление существующей установки с сохранением сопряжения:

```bash
make deploy-bin TV_IP=<tv-ip>
```

Не публикуйте `config.json`, дампы ESP32, Wi-Fi-данные и токены устройств.

## Ограничения

- Требуется root-доступ к webOS.
- DRM/HDR-защита отдельных приложений может возвращать чёрный кадр; проект её не обходит.
- Поправки Nanoleaf и ALSA-источник привязаны к конкретному оборудованию.
- Прошивка ESP32 для торшера ведётся отдельно и в этот репозиторий не включена.
